The `<Mermaid>` component renders Mermaid source as a crisp SVG, baked at
build time and re-themed live with the page. Pass the diagram as a `chart`
string, an optional `caption`, and mark an emphasised node with
`:::highlight`.

<Mermaid
  caption="no will-change vs will-change example"
  chart={`flowchart TB
  subgraph main["Main Layer - CPU"]
    A["Other Elements"]
  end
  subgraph comp["Compositing Layer - GPU"]
    B["Element with will-change"]:::highlight
  end
  main --> comp`}
/>

## One connector, many variations

Every link shares the same junction-dot motif and keeps its native arrowhead,
so direction still reads at a glance. The dot is the constant; the line varies
with the Mermaid edge style — solid (`-->`), thick (`==>`), or plain (`---`,
which drops the arrowhead and leaves just the dot).

<Mermaid
  caption="a build pipeline — solid, thick (==>) and plain (---) links"
  chart={`flowchart LR
  Src["Source"] --> Parse["Parse"]
  Parse ==> Transform["Transform"]
  Transform --> Bundle["Bundle"]
  Bundle --- Out["Output"]`}
/>

## Branching and labels

Diamonds branch; labelled edges hand the midpoint to their label instead of a
dot, so the two never collide.

<Mermaid
  caption="request routing through an auth gate"
  chart={`flowchart TB
  Req["Request"] --> Auth{"Authenticated?"}
  Auth -->|yes| Handler["Route Handler"]:::highlight
  Auth -->|no| Login["Redirect to login"]
  Handler --> Res["Response"]`}
/>

## Nested containers

Containers nest cleanly to any depth — each keeps its centred title and the
same hairline frame.

<Mermaid
  caption="a render pass streaming to the client"
  chart={`flowchart TB
  subgraph runtime["Server Runtime"]
    subgraph render["Render Pass"]
      RSC["RSC Payload"]:::highlight
      Shell["HTML Shell"]
    end
    Stream["Stream to Client"]
  end
  RSC --> Shell
  Shell -.->|chunks| Stream`}
/>
