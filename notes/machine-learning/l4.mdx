## Optimization Problem

Training a model is an **optimization problem**: find parameters $\theta^* \in \mathbb{R}^d$ that minimize the training loss,

$$
L(\theta^*) = \min_{\theta \in \mathbb{R}^d} L(\theta).
$$

Here $d$ counts the parameters ($d = n + 1$ for linear regression). An **optimization algorithm** computes a good $\theta$, usually by improving a guess step by step.

**Grid search.** Optimization that evaluates $L$ at every point of a grid of candidate parameters and keeps the best.

It needs only values of $L$, so it works for any loss when there are few parameters. With $s$ candidate values per parameter, it evaluates $s^d$ points, which is exponential in $d$ (e.g. $10^{100}$ points for 100 parameters). For linear regression, each evaluation of the MSE costs $O(mn)$.

A grid can also miss a narrow valley between its points, so grid search gives no guarantee of ending near a minimum.

Gradient methods instead use the slope of $L$ to choose each step.

## Gradient Descent

Gradient descent (Foundations) steps against the gradient. With $\theta^{(t)}$ the parameters after $t$ steps, the update reads

$$
\theta^{(t+1)} = \theta^{(t)} - \eta \nabla L(\theta^{(t)}).
$$

**Example 1. Gradient descent on the mean.**

The constant model $\hat{y} = w$ has the MSE $L(w) = \frac{1}{2m} \sum_i (y_i - w)^2$. Its derivative is $L'(w) = w - \bar{y}$, with $\bar{y}$ the mean target, so the minimizer is $w^* = \bar{y}$. One step gives $w^{(t+1)} = w^{(t)} - \eta (w^{(t)} - \bar{y})$, so

$$
w^{(t+1)} - \bar{y} = (1 - \eta)(w^{(t)} - \bar{y}).
$$

Each step multiplies the error $w^{(t)} - \bar{y}$ by $1 - \eta$. The iterates therefore converge exactly when $|1 - \eta| < 1$, that is, when $0 < \eta < 2$.

- With $0 < \eta < 1$, the iterates approach $\bar{y}$ from one side.
- With $\eta = 1$, one step lands on $\bar{y}$.
- With $1 < \eta < 2$, every step jumps over $\bar{y}$ and lands closer.
- With $\eta \ge 2$, the jumps never shrink, and gradient descent diverges.

<StepSizeSchema />

A learning rate that is too large diverges, and one that is too small converges slowly. The safe range depends on how sharply $L$ curves ($\eta < 2$ above, where $L'' = 1$).

**Learning-rate schedule.** A learning rate $\eta^{(t)}$ that changes with the step $t$, usually decaying (e.g. $\eta^{(t)} = \eta_0 / \sqrt{t}$).

Large language models typically use a warmup, a long constant phase, then a decay to zero (warmup-stable-decay).

Gradient descent stops when $\|\nabla L(\theta)\|$ is close to zero, since the gradient of a differentiable loss vanishes at a minimum.

**Ill-conditioned loss.** A loss that curves far more steeply in some directions than in others, so its contours are stretched ellipses.

One learning rate must then stay below the limit of the steepest direction, which makes progress along the flattest direction slow. Gradient descent zig-zags across the valley while it creeps along it.

**Preconditioning.** Rescaling the parameter space so that the loss curves alike in every direction.

For linear models, scaling the input features (Features) preconditions the problem, which is why it comes before gradient descent.

## Optimality Conditions

**Critical point.** A point where the gradient vanishes, $\nabla L(\theta) = \mathbf{0}$.

**First-order condition.** If $\theta^*$ is a local minimum of a differentiable $L$, then $\theta^*$ is a critical point.

The converse fails. A critical point can also be a local maximum or a **saddle point**, a critical point that is neither a local minimum nor a local maximum (e.g. $\theta_1^2 - \theta_2^2$ at $\mathbf{0}$).

**First-order convexity.** A differentiable $L$ is convex exactly when it lies above all its tangent planes:

$$
L(\mathbf{u}) \ge L(\theta) + \nabla L(\theta)^T (\mathbf{u} - \theta) \quad \text{for all } \mathbf{u}, \theta.
$$

At a critical point the tangent plane is flat, and the inequality reads $L(\mathbf{u}) \ge L(\theta)$. So for a convex $L$, every critical point is a global minimum.

**Hessian.** The $d \times d$ matrix $\nabla^2 L(\theta)$ of second partial derivatives, with entries $\partial^2 L / \partial \theta_j \partial \theta_k$.

**Positive definite matrix.** A symmetric matrix $H$ with $\mathbf{v}^T H \mathbf{v} > 0$ for every $\mathbf{v} \ne \mathbf{0}$. It is **positive semidefinite** when $\mathbf{v}^T H \mathbf{v} \ge 0$ for every $\mathbf{v}$.

*For a unit vector $\mathbf{v}$, read $\mathbf{v}^T \nabla^2 L \, \mathbf{v}$ as the curvature of $L$ along $\mathbf{v}$.*

**Second-order condition.** If $\nabla L(\theta) = \mathbf{0}$ and $\nabla^2 L(\theta)$ is positive definite, then $\theta$ is a strict local minimum.

A twice-differentiable $L$ is convex exactly when $\nabla^2 L(\theta)$ is positive semidefinite at every $\theta$.

**Example 2. The Hessian of the MSE.**

Differentiating the gradient $\nabla L = \frac{1}{m} X^T (X \tilde{\mathbf{w}} - \mathbf{y})$ of linear regression once more gives $\nabla^2 L = \frac{1}{m} X^T X$, the same matrix at every $\tilde{\mathbf{w}}$. For every $\mathbf{v}$,

$$
\mathbf{v}^T X^T X \mathbf{v} = \|X \mathbf{v}\|^2 \ge 0,
$$

so the MSE is convex. If the columns of $X$ are independent, then $X \mathbf{v} \ne \mathbf{0}$ for every $\mathbf{v} \ne \mathbf{0}$. The Hessian is then positive definite, and the minimizer is unique.

## Stochastic Gradient Descent

The training loss averages one **per-example loss** $L_i(\theta) = \ell(f_\theta(\mathbf{x}_i), y_i)$ for each example:

$$
L(\theta) = \frac{1}{m} \sum_{i=1}^{m} L_i(\theta).
$$

For linear regression, $L_i(\tilde{\mathbf{w}}) = \frac{1}{2} e_i^2$, whose gradient is $\nabla L_i = -e_i \tilde{\mathbf{x}}_i$.

**Stochastic gradient descent (SGD).** Gradient descent that steps along the gradient of one per-example loss, with $i$ drawn uniformly from $\{1, \dots, m\}$ at every step:

$$
\theta^{(t+1)} = \theta^{(t)} - \eta \nabla L_i(\theta^{(t)}).
$$

The **stochastic gradient** $\nabla L_i(\theta)$ is an unbiased estimate of the gradient. Each $i$ has probability $1/m$, so

$$
\mathbb{E}[\nabla L_i(\theta)] = \sum_{i=1}^{m} \frac{1}{m} \nabla L_i(\theta) = \nabla L(\theta).
$$

*Each step is cheap and noisy, but right on average.*

For linear regression, one SGD step costs $O(n)$. A gradient descent step costs $O(mn)$, since computing $\mathbf{e}$ and $X^T \mathbf{e}$ each touches all $m$ examples.

The SGD step $\tilde{\mathbf{w}} \leftarrow \tilde{\mathbf{w}} + \eta \, e_i \tilde{\mathbf{x}}_i$ has the shape of the perceptron update, with the residual $e_i$ in place of the label $y$.

<SgdNoiseSchema />

**Mini-batch SGD.** SGD that averages the per-example gradients over a random subset $B \subseteq \{1, \dots, m\}$, the **mini-batch**:

$$
\mathbf{g} = \frac{1}{|B|} \sum_{i \in B} \nabla L_i(\theta^{(t)}), \qquad \theta^{(t+1)} = \theta^{(t)} - \eta \, \mathbf{g}.
$$

With $|B| = 1$ it is SGD, and with $B = \{1, \dots, m\}$ it is gradient descent.

Averaging $|B|$ independent stochastic gradients divides the variance of $\mathbf{g}$ by $|B|$, at $|B|$ times the cost. The $|B|$ gradients do not depend on each other, so a GPU computes them in parallel. In practice, the examples are shuffled and split into mini-batches, so each epoch (Perceptron) uses every example once.

At a minimum $\nabla L = \mathbf{0}$, but the individual $\nabla L_i$ are not zero. With a constant $\eta$, SGD therefore keeps jittering around the minimum. It converges when $\eta^{(t)}$ decays to zero at the right speed, as stated by the **Robbins–Monro conditions**:

$$
\sum_{t=1}^{\infty} \eta^{(t)} = \infty, \qquad \sum_{t=1}^{\infty} \big(\eta^{(t)}\big)^2 < \infty.
$$

*The first sum lets the steps travel any distance; the second keeps the total noise finite.*

The schedule $\eta^{(t)} = 1 / (t + 1)^r$ meets both conditions for $0.5 < r \le 1$.

The losses of neural networks are not convex: they have many local minima and saddle points. The same algorithms still apply, and the noise of SGD can carry the iterates out of a shallow local minimum.

## Momentum and Adaptive Steps

Each method below starts from a stochastic gradient $\mathbf{g}$ of one example or a mini-batch, and changes how $\mathbf{g}$ becomes a step.

**SGD with momentum.** SGD that steps along the **momentum** $\mathbf{v}$, an exponential moving average of past stochastic gradients:

$$
\mathbf{v}^{(t+1)} = \beta_1 \mathbf{v}^{(t)} + (1 - \beta_1) \, \mathbf{g}, \qquad \theta^{(t+1)} = \theta^{(t)} - \eta \, \mathbf{v}^{(t+1)}.
$$

Here $\mathbf{v}^{(0)} = \mathbf{0}$ and $\beta_1 \in [0, 1)$, typically $0.9$. The gradient from $k$ steps ago has weight $(1 - \beta_1) \beta_1^k$ in $\mathbf{v}$, so $\mathbf{v}$ remembers about the last $1 / (1 - \beta_1)$ gradients.

*Gradient components that agree across steps add up; components that flip sign cancel.*

On an ill-conditioned loss, the zig-zag across the valley cancels while the steady pull along it builds up. Momentum then tolerates a larger learning rate than plain gradient descent.

<MomentumSchema />

**SignSGD.** SGD that keeps only the sign of each gradient coordinate $g_j$:

$$
\theta_j^{(t+1)} = \theta_j^{(t)} - \eta \operatorname{sign}(g_j).
$$

Every coordinate moves by exactly $\eta$, however large its gradient. One bit per coordinate makes the gradients cheap to send between machines in distributed training. The sign of a noisy gradient is a biased estimate, though, which causes convergence problems.

**Adagrad.** SGD with one learning rate $\eta / \sqrt{s_j}$ per coordinate, where $s_j$ sums all past squared gradients $g_j^2$ of coordinate $j$.

**Adam.** SGD with momentum and one adaptive learning rate per coordinate $j$:

$$
\begin{aligned}
\mathbf{v}^{(t+1)} &= \beta_1 \mathbf{v}^{(t)} + (1 - \beta_1) \, \mathbf{g}, \\
s_j^{(t+1)} &= \beta_2 s_j^{(t)} + (1 - \beta_2) \, g_j^2, \\
\theta_j^{(t+1)} &= \theta_j^{(t)} - \frac{\eta}{\sqrt{s_j^{(t+1)}}} \, v_j^{(t+1)}.
\end{aligned}
$$

Typical values are $\beta_1 = 0.9$ and $\beta_2 = 0.999$. Papers write $\mathbf{m}$ and $\mathbf{v}$ for $\mathbf{v}$ and $\mathbf{s}$, but this course keeps $m$ for the number of examples.

The average $s_j$ tracks the typical size of $g_j^2$. Coordinates with large gradients therefore take small steps, and coordinates with small gradients take large ones. Unlike the sum of Adagrad, the moving average forgets old gradients, so the learning rate does not shrink forever.

*Without memory ($\beta_1 = \beta_2 = 0$), the step uses $v_j / \sqrt{s_j} = g_j / |g_j|$, and Adam becomes SignSGD.*

Implementations add a small $\epsilon$ to $\sqrt{s_j}$ to avoid dividing by zero. They also divide $\mathbf{v}$ and $\mathbf{s}$ by $1 - \beta_1^t$ and $1 - \beta_2^t$, which undoes their start at $\mathbf{0}$. Adam stores $\theta$, $\mathbf{v}$ and $\mathbf{s}$, three vectors the size of the model, and performs well in practice, in particular on neural networks.

**AdamW.** Adam with **weight decay**: each step also shrinks $\theta$ toward $\mathbf{0}$, separately from the adaptive step.

**Muon.** SGD with momentum for a weight matrix $W$, one layer of a neural network, that steps along the matrix sign of the momentum. With $G$ the stochastic gradient of $W$,

$$
\begin{aligned}
M^{(t+1)} &= \beta_1 M^{(t)} + (1 - \beta_1) \, G, \\
W^{(t+1)} &= W^{(t)} - \eta \operatorname{msign}(M^{(t+1)}).
\end{aligned}
$$

Every matrix factors as $M = U \Sigma V^T$, its **singular value decomposition (SVD)**. The matrices $U$ and $V$ have orthonormal columns, and the diagonal $\Sigma$ holds the **singular values**, how much $M$ stretches along each direction. The **matrix sign** $\operatorname{msign}(M) = U V^T$ sets every singular value to $1$.

*The matrix sign keeps the directions of the momentum and drops how strongly each one is favoured, as the sign does for coordinates.*

The update therefore has operator norm $1$, its largest stretch, and pushes equally hard in every direction. In practice, five Newton–Schulz iterations approximate $\operatorname{msign}$ with matrix products only, which suits GPUs better than an SVD. Muon updates only the 2D weight matrices, with $\eta \approx 0.02$. The embeddings, biases, gains and routers use AdamW.

## Non-smooth Optimization

The MAE has a kink: $|e|$ has no derivative at $e = 0$, so its gradient does not exist where a residual is zero.

**Subgradient.** A vector $\mathbf{g}$ such that the plane through $(\theta, L(\theta))$ with slope $\mathbf{g}$ stays below $L$:

$$
L(\mathbf{u}) \ge L(\theta) + \mathbf{g}^T (\mathbf{u} - \theta) \quad \text{for all } \mathbf{u}.
$$

The set of all subgradients at $\theta$ is the **subdifferential** $\partial L(\theta)$.

The definition is first-order convexity with $\mathbf{g}$ in place of $\nabla L$, but it needs no derivative. If $L$ is convex and differentiable at $\theta$, then $\partial L(\theta) = \{\nabla L(\theta)\}$.

Adding the inequalities of two functions shows that the sum of their subgradients is a subgradient of their sum.

**Example 3. Subgradients of the absolute value.**

The function $h(e) = |e|$ has the subdifferential

$$
\partial h(e) = \begin{cases} \{-1\} & \text{if } e < 0, \\ [-1, 1] & \text{if } e = 0, \\ \{1\} & \text{if } e > 0. \end{cases}
$$

<SubgradientSchema />

**Subgradient descent.** Gradient descent with a subgradient $\mathbf{g} \in \partial L(\theta^{(t)})$ in place of the gradient:

$$
\theta^{(t+1)} = \theta^{(t)} - \eta \, \mathbf{g}.
$$

**Common mistake.** A subgradient step does not always decrease $L$. At a kink, a negative subgradient can point uphill (e.g. for $L = |\theta_1| + 2 |\theta_2|$ at $(1, 0)$, the subgradient $(1, 2)$ leads to $L = 1 + 3\eta$). Subgradient descent therefore uses a decaying learning rate and keeps the best iterate.

The chain rule carries over when the inner function is affine. If $h$ is convex and $q(\theta) = \mathbf{a}^T \theta + c$, then $h' \mathbf{a}$ is a subgradient of $h(q(\theta))$ for every $h' \in \partial h(q(\theta))$.

**Example 4. A subgradient of the linear MAE.**

The MAE of linear regression averages $|e_i|$, where $e_i = y_i - \tilde{\mathbf{x}}_i^T \tilde{\mathbf{w}}$ is affine in $\tilde{\mathbf{w}}$ with gradient $-\tilde{\mathbf{x}}_i$. The chain rule and the sum of subgradients give

$$
\mathbf{g} = -\frac{1}{m} \sum_{i=1}^{m} \operatorname{sign}(e_i) \, \tilde{\mathbf{x}}_i \in \partial L(\tilde{\mathbf{w}}),
$$

where $\operatorname{sign}(0)$ may take any value in $[-1, 1]$.

*Every example pulls with the same strength whatever its residual, so a distant outlier pulls no harder than a close example.*

**Stochastic subgradient descent.** SGD with a subgradient $\mathbf{g} \in \partial L_i(\theta^{(t)})$ of a random per-example loss, usually still called SGD.

For the linear MAE, one example gives $\mathbf{g} = -\operatorname{sign}(e_i) \, \tilde{\mathbf{x}}_i$. For linear regression, the direction and the cost of one step are:

| | **MSE** (differentiable) | **MAE** (not differentiable) |
|---|---|---|
| **gradient descent** | $\nabla L$, $O(mn)$ | $\mathbf{g} \in \partial L$, $O(mn)$ |
| **SGD** | $\nabla L_i$, $O(n)$ | $\mathbf{g} \in \partial L_i$, $O(n)$ |

## Constrained Optimization

**Constrained problem.** An optimization problem that minimizes $L$ only over a **constraint set** $C \subset \mathbb{R}^d$:

$$
\min_{\theta \in C} L(\theta).
$$

**Convex set.** A set $C$ that contains the segment between any two of its points: $\alpha \mathbf{u} + (1 - \alpha) \mathbf{v} \in C$ for all $\mathbf{u}, \mathbf{v} \in C$ and $\alpha \in [0, 1]$.

A ball or a filled polygon is convex (not a crescent: the segment between its tips leaves it). The intersection of convex sets is convex.

**Projection.** The point of $C$ nearest to a point $\theta'$:

$$
P_C(\theta') = \arg\min_{\mathbf{v} \in C} \|\mathbf{v} - \theta'\|.
$$

For a closed convex set $C$, the projection exists and is unique.

**Projected gradient descent.** Gradient descent that projects back onto $C$ after every step:

$$
\theta^{(t+1)} = P_C\big(\theta^{(t)} - \eta \nabla L(\theta^{(t)})\big).
$$

<ProjectionSchema />

Projected SGD uses a stochastic gradient instead, with the same convergence properties as SGD.

The projection runs at every step, so its cost matters. Projecting onto the ball $\{\theta : \|\theta\| \le r\}$ only rescales, $P_C(\theta') = \theta' \min(1, r / \|\theta'\|)$. Projecting onto the L1 ball $\{\theta : \|\theta\|_1 \le r\}$, a diamond in 2D, needs a sort of the coordinates.

**Penalty method.** Solving a constrained problem as an unconstrained one, by adding to $L$ a term that penalizes leaving $C$.

- **Indicator.** With $I_C(\theta) = 0$ on $C$ and $\infty$ outside, minimizing $L + I_C$ over $\mathbb{R}^d$ is the constrained problem itself. The objective is not continuous, though, so gradient methods cannot use it.
- **Squared violation.** For $C = \{\theta : A\theta = \mathbf{b}\}$, minimize $L(\theta) + \lambda \|A\theta - \mathbf{b}\|^2$, where $\lambda > 0$ trades loss against violation.
- **Lagrange multipliers.** Linear penalties $\boldsymbol{\lambda}^T (A\theta - \mathbf{b})$, whose weights $\boldsymbol{\lambda}$ are optimized as well.

Regularization (Generalization) has this form, with a penalty on the size of $\theta$.

## Implementation

Gradient descent, mini-batch SGD and Adam on the data of the linear regression implementation:

```python
import numpy as np

# 50 examples of y = 3 x1 - 2 x2 + 1 plus noise, bias folded in
rng = np.random.default_rng(0)
X = np.c_[rng.random((50, 2)), np.ones(50)]
y = X @ [3, -2, 1] + 0.1 * rng.standard_normal(50)

def grad(w, B):  # gradient of the MSE on the examples B
    e = y[B] - X[B] @ w
    return -X[B].T @ e / len(B)

w = np.zeros(3)
for t in range(5000):  # gradient descent
    w -= 0.2 * grad(w, np.arange(50))

w_sgd = np.zeros(3)
for t in range(5000):  # mini-batch SGD, decaying learning rate
    B = rng.choice(50, 5, replace=False)
    w_sgd -= 1 / (t + 1) ** 0.6 * grad(w_sgd, B)

w_adam, v, s = np.zeros(3), np.zeros(3), np.zeros(3)
for t in range(5000):  # Adam, without bias correction
    g = grad(w_adam, rng.choice(50, 5, replace=False))
    v = 0.9 * v + 0.1 * g
    s = 0.999 * s + 0.001 * g**2
    w_adam -= 0.003 * v / (np.sqrt(s) + 1e-8)

print(w.round(2), w_sgd.round(2), w_adam.round(2))
# [ 3.05 -1.91  0.92] [ 3.03 -1.91  0.93] [ 3.06 -1.89  0.92]
```
