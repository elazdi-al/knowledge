## Model

**Perceptron.** A binary classifier that thresholds a weighted sum, the **score**:

$$
z = \mathbf{w}^T \mathbf{x} + b, \qquad \hat{y} = \begin{cases} +1 & \text{if } z \ge 0, \\ -1 & \text{otherwise.} \end{cases}
$$

Its parameters are the **weight vector** $\mathbf{w} \in \mathbb{R}^n$ and the **bias** $b \in \mathbb{R}$.

*A growing feature pushes $\hat{y}$ toward the sign of its weight.*

**Bias folding.** Appending $1$ to the input moves the bias into the weights:

$$
z = \tilde{\mathbf{w}}^T \tilde{\mathbf{x}}, \qquad \tilde{\mathbf{w}} = (\mathbf{w}, b), \quad \tilde{\mathbf{x}} = (\mathbf{x}, 1).
$$

**Decision boundary.** The hyperplane $\mathbf{w}^T \mathbf{x} + b = 0$, a line when $n = 2$.

Its normal vector $\mathbf{w}$ points to the side classified $+1$, boundary included.

**Margin.** An example's distance to the boundary, negated on the wrong side:

$$
\gamma_i = \frac{y_i (\mathbf{w}^T \mathbf{x}_i + b)}{\|\mathbf{w}\|}.
$$

The margin of a dataset is its smallest margin, $\gamma = \min_i \gamma_i$.

**Linearly separable.** Classes that some hyperplane strictly separates (e.g. AND, but not XOR).

## Loss

**Zero-one loss.** The loss that is $1$ on a mistake ($\hat{y} \ne y$) and $0$ otherwise.

Its training loss is the fraction of misclassified training examples.

It is piecewise constant, so gradient descent gets no direction from it.

## Training

**Perceptron algorithm.** Training that corrects the parameters after each mistake.

1. Start from $\mathbf{w} = \mathbf{0}$ and $b = 0$.
2. For each training example $(\mathbf{x}, y)$ with $\hat{y} \ne y$, update
   $$
   \mathbf{w} \leftarrow \mathbf{w} + \eta y \mathbf{x}, \qquad b \leftarrow b + \eta y.
   $$
3. Repeat step 2 until a full pass, an **epoch**, makes no mistake.

*An update shifts that input's score by $\eta y (\|\mathbf{x}\|^2 + 1)$, toward its label.*

## Convergence

The theorem uses folded vectors, written $\mathbf{x}$ and $\mathbf{w}$ without tildes.

**Perceptron convergence theorem.** Assume the inputs satisfy:

- **Bounded length.** $\|\mathbf{x}_i\| \le R$ for all $i$.
- **Margin $\gamma$.** Some unit vector $\mathbf{w}^*$ has $y_i \mathbf{w}^{*T} \mathbf{x}_i \ge \gamma > 0$ for all $i$.

Then from $\mathbf{w} = \mathbf{0}$, the total number $k$ of mistakes over all epochs satisfies

$$
k \le \frac{R^2}{\gamma^2}.
$$

So training stops on separable data, at zero training loss.

The bound shrinks with the margin and is independent of $m$, $n$ and $\eta$.

The folded margin $\gamma$ is at most the original margin of the same boundary.

**Common mistake.** The perceptron does not find the best separating boundary. It stops at the first boundary with no training mistake, which can pass close to some examples.

*Alignment grows like $k$, length only like $\sqrt{k}$, and length bounds alignment.*

**Proof.** Let $\mathbf{w}_k$ be the weights after $k$ updates.

The $k$-th update fixes a mistake on some $(\mathbf{x}_i, y_i)$, so $y_i \mathbf{w}_{k-1}^T \mathbf{x}_i \le 0$.

1. **Alignment grows linearly.** Each update adds at least $\eta \gamma$ to $\mathbf{w}_k^T \mathbf{w}^*$:
   $$
   \mathbf{w}_k^T \mathbf{w}^* = \mathbf{w}_{k-1}^T \mathbf{w}^* + \eta y_i \mathbf{x}_i^T \mathbf{w}^* \ge \mathbf{w}_{k-1}^T \mathbf{w}^* + \eta \gamma,
   $$
   so $\mathbf{w}_k^T \mathbf{w}^* \ge k \eta \gamma$.
2. **Length grows slowly.** The middle term is $\le 0$ on a mistake:
   $$
   \|\mathbf{w}_k\|^2 = \|\mathbf{w}_{k-1}\|^2 + 2 \eta y_i \mathbf{w}_{k-1}^T \mathbf{x}_i + \eta^2 \|\mathbf{x}_i\|^2 \le \|\mathbf{w}_{k-1}\|^2 + \eta^2 R^2,
   $$
   so $\|\mathbf{w}_k\|^2 \le k \eta^2 R^2$.
3. **Combine.** By the Cauchy-Schwarz inequality and $\|\mathbf{w}^*\| = 1$,
   $$
   k \eta \gamma \le \mathbf{w}_k^T \mathbf{w}^* \le \|\mathbf{w}_k\| \le \sqrt{k}\, \eta R,
   $$
   so $\sqrt{k} \le R / \gamma$.

Squaring gives $k \le R^2 / \gamma^2$.

## Limits

On non-separable data, every epoch makes a mistake and training never stops.

Even XOR defeats the perceptron: no line separates its two classes.

## Implementation

The perceptron algorithm in NumPy, trained on AND:

```python
import numpy as np

# AND: only (1, 1) is labeled +1
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
Y = np.array([-1, -1, -1, 1])

w, b, eta = np.zeros(2), 0.0, 1.0

mistakes = True
while mistakes:  # one epoch per pass
    mistakes = False
    for x, y in zip(X, Y):
        y_hat = 1 if w @ x + b >= 0 else -1
        if y_hat != y:
            w += eta * y * x
            b += eta * y
            mistakes = True

print(w, b)  # [2. 1.] -3.0
```
