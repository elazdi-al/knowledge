## Learning from Data

**Example.** A single data point $(\mathbf{x}, y)$, where $\mathbf{x}\in\mathbb{R}^n$ is the feature vector and $y\in\mathcal{Y}$ is the target/label.

**Model.** A prediction function $f_\theta:\mathbb{R}^n\to\mathcal{Y}$ that maps an input feature vector $\mathbf{x}$ to a predicted output $\hat{y}=f_\theta(\mathbf{x})$, where $\theta$ denotes the model’s learned parameters.

**Training set.** A set of examples $\{(\mathbf{x}_i,y_i)\}_{i=1}^m$ used to learn the model parameters $\theta$.

**Classification.** Predicting a discrete class $y\in\{1,\dots,K\}$.

**Binary classification.** Classification with exactly two classes, typically $y\in\{0,1\}$.

## Linear Classification

**Linear classifier.** A model that assigns a class based on which side of a linear decision boundary an example $\mathbf{x}\in\mathbb{R}^n$ lies:

$$
f:\mathbb{R}^n\to\{-1,+1\},\qquad
f(\mathbf{x})=\operatorname{sign}(\mathbf{w}^\top\mathbf{x}+b),
$$

where $\mathbf{w}\in\mathbb{R}^n$, $b\in\mathbb{R}$, and

$$
\operatorname{sign}(z)=
\begin{cases}
+1 & z\ge 0,\\
-1 & z<0.
\end{cases}
$$

**Decision boundary.** The decision boundary is the hyperplane $\mathbf{w}^T \mathbf{x} + b = 0$, a line when $n = 2$.

Its normal vector $\mathbf{w}$ points to the side classified $+1$.

**Perceptron.** A **linear binary classifier** that predicts the label of an input $\mathbf{x}\in\mathbb{R}^d$ using

$$
\hat y=\operatorname{sign}(\mathbf{w}^\top\mathbf{x}+b),
$$

with $\mathbf{w}\in\mathbb{R}^d$ the weight vector, $b\in\mathbb{R}$ the bias, and $\hat y\in\{-1,+1\}$.

Given training examples $(\mathbf{x}_i,y_i)$ with $y_i\in\{-1,+1\}$, it starts with initial parameters $\mathbf w_0\in\mathbb{R}^d,\; b_0\in\mathbb{R}$.
Then, for each misclassified example :

$$
y_i(\mathbf{w}^\top\mathbf{x}_i+b)\le 0,
$$

it updates

$$
\mathbf{w}\leftarrow\mathbf{w}+\eta y_i\mathbf{x}_i,
$$

$$
b\leftarrow b+\eta y_i,
$$

where $\eta>0$ is the learning rate.

**Perceptron Convergence Theorem.** If the training set is **linearly separable**, then the perceptron makes a finite number of mistakes and eventually finds parameters $\mathbf w,b$ that correctly classify every training example.

Assume there exists some separating vector $\mathbf w^*$ such that, for every training example $(\mathbf x_i,y_i)$,

$$
y_i\,\mathbf w^{*\top}\mathbf x_i \ge \gamma > 0,
$$

where $\gamma$ is the **margin**, and assume

$$
\|\mathbf x_i\|\le R
$$

for all $i$, where $R$ is the maximum norm of any training input.

Then the number of perceptron mistakes is at most

$$
\left(\frac{R\|\mathbf w^*\|}{\gamma}\right)^2.
$$

If $\|\mathbf w^*\|=1$, this becomes

$$
\left(\frac{R}{\gamma}\right)^2.
$$

So, for linearly separable data, the perceptron is guaranteed to converge after finitely many updates.

## Regression

**Regression.** A supervised learning task where, given an example $\mathbf{x}\in\mathbb{R}^n$, the goal is to predict a real-valued output:

$$
f:\mathbb{R}^n\to\mathbb{R}.
$$

**Linear regression.** A regression model that predicts the output as a linear function of the example $\mathbf{x}\in\mathbb{R}^n$:

$$
f:\mathbb{R}^n\to\mathbb{R},\qquad
f(\mathbf{x})=\mathbf{w}^\top\mathbf{x}+b,
$$

where $\mathbf{w}\in\mathbb{R}^n$ is the weight vector, $b\in\mathbb{R}$ is the bias, and $f(\mathbf{x})\in\mathbb{R}$ is the predicted value.

Equivalently, the bias can be folded into augmented vectors:

$$
\tilde{\mathbf{x}}
=
\begin{bmatrix}
\mathbf{x}\\
1
\end{bmatrix}
\in\mathbb{R}^{n+1},
\qquad
\tilde{\mathbf{w}}
=
\begin{bmatrix}
\mathbf{w}\\
b
\end{bmatrix}
\in\mathbb{R}^{n+1},
$$

so that

$$
f(\mathbf{x})
=
\tilde{\mathbf{w}}^\top\tilde{\mathbf{x}}.
$$


**Residual.** The residual $e_i = y_i - \hat{y}_i$ is the error on example $i$, its vertical distance to the hyperplane.

## Matrix Form

**Target vector.** The vector containing the true outputs associated with all examples in a dataset:

$$
\mathbf{y}=
\begin{bmatrix}
y_1\\
y_2\\
\vdots\\
y_N
\end{bmatrix}
\in\mathbb{R}^N,
$$

where $y_i$ is the target value of example $\mathbf{x}_i$.

**Design matrix.** The matrix containing all input examples of a dataset, with one example per row:

$$
X=
\begin{bmatrix}
\mathbf{x}_1^\top\\
\mathbf{x}_2^\top\\
\vdots\\
\mathbf{x}_N^\top
\end{bmatrix}
\in\mathbb{R}^{N\times n},
$$

where $N$ is the number of examples and $n$ is the number of features.

**Prediction vector.** The prediction vector $\hat{\mathbf{y}} = X \tilde{\mathbf{w}} \in \mathbb{R}^m$ holds all $m$ predictions. Row $i$ of the product is $\tilde{\mathbf{x}}_i^T \tilde{\mathbf{w}} = \hat{y}_i$.

**Residual vector.** The residual vector $\mathbf{e} = \mathbf{y} - X \tilde{\mathbf{w}} \in \mathbb{R}^m$ holds all $m$ residuals $e_i$.

**Underdetermined problem.** A problem with fewer independent equations than unknowns, so it generally has infinitely many solutions.

For a linear system

$$
A\mathbf{x}=\mathbf{b},
$$

it is underdetermined when the system does not provide enough independent constraints to uniquely determine $\mathbf{x}$.

**Overparameterization.** A model is overparameterized when it has more trainable parameters than needed to fit the training data, often more parameters than training examples.

For linear regression,

$$
X\mathbf{w}=\mathbf{y},
$$

the problem is overparameterized when the number of parameters exceeds the number of examples:

$$
n>N.
$$

This typically makes the system underdetermined, so multiple parameter vectors $\mathbf{w}$ may fit the training data exactly.

## Loss Functions

**Loss function.** A function that measures how wrong a model’s prediction is compared with the true target:

$$
\ell(\hat y,y)\in\mathbb{R}_{\ge 0},
$$

where $\hat y$ is the prediction and $y$ is the true target; a smaller loss means a better prediction.

**Two desirable properties.**

1. **Statistical quality:** minimizing the loss should lead to good predictions on the actual task.
2. **Computational tractability:** the loss should be easy to optimize, for example by being differentiable or convex.

**Statistical–computational trade-off.** A loss that best represents the true task may be difficult to optimize, while an easier-to-optimize loss may only approximate the true objective.

For example, the $0$-$1$ loss directly measures classification errors,

$$
\ell_{0/1}(\hat y,y)=\mathbf{1}[\hat y\neq y],
$$

but is difficult to optimize, so surrogate losses such as logistic loss or hinge loss are often used instead.

**Training loss.** The average loss of a model over all examples in the training set:

$$
L_{\text{train}}(\theta)
=
\frac{1}{N}
\sum_{i=1}^{N}
\ell\big(f_\theta(\mathbf{x}_i),y_i\big),
$$

where $\theta$ are the model parameters, $f_\theta(\mathbf{x}_i)$ is the prediction, and $y_i$ is the true target.

**Mean Squared Error (MSE).** A loss function that measures the average squared difference between predictions and true targets:

$$
\operatorname{MSE}(\theta)
=
\frac{1}{N}
\sum_{i=1}^{N}
\left(f_\theta(\mathbf{x}_i)-y_i\right)^2,
$$

where $f_\theta(\mathbf{x}_i)$ is the prediction and $y_i$ is the true target; smaller MSE means predictions are closer to the targets.

**Outlier.** A data point that lies unusually far from the rest of the observations in a dataset.

For MSE, outliers can have a large influence because errors are squared, giving very large errors much more weight.

**Robust loss.** A loss function designed to be less sensitive to outliers, so unusually large errors do not dominate the total loss as strongly as with MSE.

**Mean Absolute Error (MAE).** A loss function equal to the average absolute difference between the true values $y_i$ and predictions $\hat y_i$:

$$
\mathrm{MAE}=\frac{1}{N}\sum_{i=1}^{N}|y_i-\hat y_i|.
$$

Unlike MSE, MAE is more robust to outliers because errors are not squared.

## Minima and Convexity

**Convexity.** A function $f$ is convex if, for any $x_1,x_2$ in its domain and any $\lambda\in[0,1]$,

$$
f(\lambda x_1+(1-\lambda)x_2)
\le
\lambda f(x_1)+(1-\lambda)f(x_2).
$$

It is **strictly convex** if the inequality is strict for $x_1\neq x_2$ and $\lambda\in(0,1)$.

For a convex function, every local minimum is a global minimum.

**Sum of convex functions.** If $L_1,\ldots,L_n$ are convex, then

$$
L(\mathbf{w})=\sum_{i=1}^n L_i(\mathbf{w})
$$

is also convex.

--- 

**Global minimum.** If

$$
L(\mathbf{w}^\star)\le L(\mathbf{w}),\qquad \forall \mathbf{w},
$$

then $\mathbf{w}^\star$ is a global minimum of $L$.

**Local minimum.** If

$$
L(\mathbf{w}^\star)\le L(\mathbf{w})
$$

for all $\mathbf{w}$ sufficiently close to $\mathbf{w}^\star$, then $\mathbf{w}^\star$ is a local minimum of $L$.

**Importance of convexity.** Convexity is a desirable computational property because optimization does not suffer from bad local minima: any local minimum found is global.
