## Learning from Examples

**Machine learning.** Learning a function from examples of its inputs and desired outputs, instead of programming its rules by hand.

A model learns from **examples** $(\mathbf{x}, y)$: an input $\mathbf{x} \in \mathbb{R}^n$ and its **target** $y$.

The entries $x_1, \dots, x_n$ of $\mathbf{x}$ are its **features**.

**Classification.** Predicting a target from a finite set of classes, called a **label**.

Binary classification has two classes, written $-1$ and $+1$.

**Regression.** Predicting a real-valued target.

The goal of regression is **prediction**, the output for a new input (the weight of a person 170 cm tall). It can also be **interpretation**, the effect of an input on the output (are taller people heavier?).

Regression finds correlations, not causes, so an interpretation needs caution.

**Model.** A function $f_\theta$ that predicts $\hat{y} = f_\theta(\mathbf{x})$ from an input.

Its **parameters** $\theta$ are the values that training learns.

**Training set.** The $m$ examples $(\mathbf{x}_i, y_i)$ that training fits $\theta$ on.

**Loss function.** A function $\ell(\hat{y}, y)$ that scores the error of one prediction.

**Training**, also called learning or fitting, minimizes the **training loss**, the average loss over the training set:

$$
L(\theta) = \frac{1}{m} \sum_{i=1}^{m} \ell(f_\theta(\mathbf{x}_i), y_i).
$$

## Minima and Convexity

**Minimum.** A point $\theta^*$ where $L$ is lowest, over all $\theta$ (**global**) or a ball (**local**):

$$
B_\epsilon = \{\theta : \|\theta - \theta^*\| < \epsilon\}, \quad \epsilon > 0.
$$

It is **strict** when every other $\theta$ in that region has a strictly higher loss.

| | **minimum** | **strict minimum** |
|---|---|---|
| **global** | $L(\theta^*) \le L(\theta)\ \forall \theta$ | $L(\theta^*) < L(\theta)\ \forall \theta \ne \theta^*$ |
| **local**, some $\epsilon > 0$ | $L(\theta^*) \le L(\theta)\ \forall \theta \in B_\epsilon$ | $L(\theta^*) < L(\theta)\ \forall \theta \in B_\epsilon \setminus \{\theta^*\}$ |

Every global minimum is local, and a strict global minimum is the only minimizer.

**Underdetermined problem.** A problem whose lowest loss is reached by many $\theta$ (e.g. a line $\hat{y} = w x + b$ fitted to a single point: every line through the point fits).

**Convex function.** A function whose graph never rises above its chords (e.g. $\theta^2$; not $\theta^3$, which rises above its chord on $[-1, 0]$):

$$
L(t\theta + (1 - t)\theta') \le t L(\theta) + (1 - t) L(\theta'), \quad t \in [0, 1].
$$

It is **strictly convex** when the inequality is strict for $\theta \ne \theta'$ and $0 < t < 1$.

*A convex loss has no false bottom: where descent stops, the loss is lowest.*

Every local minimum of a convex function is global.

A sum of convex functions is convex. A training loss whose per-example losses are convex in $\theta$ is therefore convex.

A strictly convex function has at most one minimizer.

**Common mistake.** A convex loss does not always have a unique minimizer. It can reach its lowest value at many $\theta$, making the problem underdetermined. Strict convexity rules this out.

## Gradient Descent

**Gradient.** The vector $\nabla L(\theta)$ of the partial derivatives $\partial L / \partial \theta_j$, one per parameter. It points in the direction in which $L$ increases fastest.

**Gradient descent.** Minimizing $L$ by repeated steps against its gradient:

$$
\theta \leftarrow \theta - \eta \nabla L(\theta).
$$

**Learning rate.** The step size $\eta > 0$.

*The gradient points uphill, so a small step against it goes downhill.*

It starts from some $\theta$, often $\mathbf{0}$, and stops when $L$ stops decreasing.

On a convex loss with a small enough $\eta$, it reaches the global minimum.

Otherwise it can stop in a non-global local minimum (e.g. on neural networks).

A good loss is therefore:

- non-negative, and zero when $\hat{y} = y$;
- symmetric for regression, so an error costs the same above and below the target;
- differentiable in $\theta$, so gradient descent can use it;
- convex in $\theta$ when possible, so every local minimum is global.
